# Монита

Архитектурын ангийн шинэ жилийн монитагийн сайт.

- Статик сайт (GitHub Pages), өгөгдөл ба Google нэвтрэлт: Firebase төсөл `monitarxi` (Firestore, Spark төлөвлөгөө).
- `js/app.js` — нэвтрэлт, бүртгэл, профайл, нүүр, мэдэгдэл.
- `js/admin.js` — админ: оролцогчид, монита эхлүүлэх/цуцлах, өдөр ба сэдэв, сүүлийн өдөр, мэдэгдэл, зар.
- `js/matching.js` — холбох алгоритм (±1 жил, алтан монита, хасагдсан хүний холбоосыг нөхөх).
- `js/fb.js` — Firestore-ийн бүх үйлдэл.
- `firestore.rules` — Firebase консолд нийтэлсэн хамгаалалтын дүрэм. Өөрчилбөл консолд дахин нийтэлнэ.
- `vendor/` — Firebase SDK (esbuild багц) ба pdf.js.

Шинэчлэл гаргахдаа бүх импортын `?v=` дугаарыг нэг ижил өсгөнө.
